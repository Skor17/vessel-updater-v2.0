Matching
  • Rows are matched only by DB Number — vessel names are never used for matching, since names can change.
  • Each row's Primary DB Number is checked first; if there's no match, its Secondary DB Number is tried as a fallback.
  • Rows with no match on either DB Number are left completely unchanged.
Fields updated
  • Only Vessel Name, IMO Number, Handover Date, and Shop Test Date are ever changed on existing rows. Every other column is left exactly as it was.
  • A blank value in the database never erases an existing value in your file.
  • Handover Date is only updated when the database date is 1 Jan 2025 or later.
  • If a Shop Test cell already contains the word "shoptested", it is left untouched.
  • All dates are written as DD/MM/YYYY.
New vessels
  • Any database record whose DB Number doesn't match an existing row is added as a new row at the bottom of the sheet, in database order.
  • New rows are filled in from every matching column in the database (including Hull Number, Owner, DB Numbers, Licensee and Vessel Type), and are styled to match the existing table.
  • Handover Date on a new row still only gets filled in if it's 1 Jan 2025 or later — otherwise it's left blank, just like on an existing row.
  • A database record with no DB Number at all can't be reliably tracked, so it's skipped rather than added.
